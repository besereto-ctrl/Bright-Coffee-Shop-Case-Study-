Project Overview 
- This project analyzes sales Performance for Bright Coffee Shop to identify trends,
  best selling products, peak hours and customer behaviour to improve business decisions. 

Objectives 
-  Clean and process raw sales data 
-  Analyze product performance and revenue trends 
-  Visualize key insights with dashboards
-  Provide recommendations

Tools and Technologies used

- Excel - Gantt Charts, Pivot tables and Charts 
- Databricks - Data querying and processing 
- Miro - Plan
- PowerPoint - Presentation
